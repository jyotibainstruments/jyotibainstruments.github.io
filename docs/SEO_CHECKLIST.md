# SEO checklist — JIE website

Status at the end of Phase 7: every build-time item below is **done and enforced by code** — a regression fails `npm run build` or a Lighthouse assertion. The owner tasks at the bottom are actions outside the site (Google accounts, third-party listings).

## Build-time SEO (enforced, automated)

- [x] **One `<h1>` per page**, unique `<title>` ≤ 60 chars and meta description ≤ 155 on all 22 pages (Zod schemas fail the build otherwise).
- [x] **Canonical URL** on every page, correct per route, `trailingSlash: 'always'` (astro.config.mjs).
- [x] **`lang="en-IN"`**, Open Graph (og:title/description/url/image/locale en_IN) and Twitter `summary_large_image` tags from one layout (`src/layouts/BaseLayout.astro`).
- [x] **robots.txt** at `/robots.txt` referencing `/sitemap-index.xml` (generated by `src/pages/robots.txt.ts`).
- [x] **Sitemap** auto-generated by `@astrojs/sitemap`; 22 production URLs; `/404` excluded (filter in astro.config.mjs).
- [x] **JSON-LD per AGENTS.md rules**: `Organization` + `WebSite` site-wide; `LocalBusiness` ×2 with the two real addresses on `/contact/` and on `/`; `Service` on all 10 service pages; `BreadcrumbList` on all inner pages; `CollectionPage` on `/about/` and `/clients/`. **No** `Product`, `Offer` or `Review` markup anywhere (no price/review data exists).
- [x] **404**: `noindex, nofollow`, canonical to `/404/`, no JSON-LD, outside the sitemap.
- [x] **Descriptive anchor text** and real `<a href>` navigation everywhere (linkinator checks all internal links on every build).
- [x] **No doorway pages**: the three location pages exist only because each has ≥ 250 words of unique, source-backed copy (min-length enforced by the Zod schema in `src/lib/content.ts`).
- [x] **No banned claims**: "NABL"/"accredited" never appear; ISO line stays behind `showIsoClaim: false`; no invented numbers/years/counts — checked against `docs/CONTENT.md` in each phase's QA.
- [x] **Core Web Vitals**: Lighthouse 100/100/100/100 on `/`, `/services/calibration/mechanical-pressure/`, `/products/`, `/contact/`; LCP ≤ 1.0 s, CLS 0 (fonts preloaded, self-hosted WOFF2, explicit image dimensions, no layout-shifting UI).
- [x] **Prefetch** on hover for internal links (Astro `prefetchAll`).

## One-off owner tasks before/after go-live

1. [ ] **Google Search Console.** Create/verify a property for `https://jyotibainstruments.github.io` (URL prefix, or Domain verification if the owner controls DNS elsewhere). Submit `https://jyotibainstruments.github.io/sitemap-index.xml` under Sitemaps.
2. [ ] **Bing Webmaster Tools.** Import the verified site from Google Search Console; submit the same sitemap.
3. [ ] **Rich Results Test.** Run <https://search.google.com/test/rich-results> on `/`, `/contact/`, `/services/calibration/` and one location page; expect LocalBusiness/Service/BreadcrumbList to parse without errors (warnings about optional fields are acceptable).
4. [ ] **Ask Google to index** the key pages after first deploy (URL inspection → Request indexing): `/`, `/services/`, `/contact/`.
5. [ ] **Google Business Profile.** If the owner wants the lab visible in map results, create a profile for the Udyambag address with the exact same name/address/phone strings the site uses (character-for-character — NAP consistency). This is a separate Google product; the site itself needs no change.
6. [ ] **Back-link seeds (legit sources only):** the JIE domain, KLS/industry directories, or supplier pages only where JIE genuinely appears. Do not buy links.
7. [ ] **Analytics (optional).** Set `PUBLIC_GA_ID` (GA4 Measurement ID) to enable the built-in conditional loader. See README §Analytics. If enabled, confirm the privacy page wording still matches.
8. [ ] **After catalogues go live:** once a company is `published: true` and its PDF added, the sitemap gains `/products/<slug>/` automatically — resubmission in GSC is not required, but check Coverage after a week.

## Cadence

- **Every push:** the deploy workflow runs the build gate (0 warnings), linkinator and Lighthouse assertions — a red run means a deploy did not publish; fix before anything else.
- **Monthly (5 min):** GSC → Coverage (index errors), Core Web Vitals report, and Performance → top queries. Expected early impression sources: "calibration services Belgaum", "pressure gauge calibration Belgaum", "instrument calibration Hubli", brand + "instruments".
- **When facts change** (phone, address, customers): edit `src/data/*.json` / `src/config/site.ts` only — canonical, sitemap and JSON-LD follow automatically. Keep `docs/CONTENT.md` the single source of truth so future edits stay factual.

## Known SEO limits (accepted)

- Company pages (`/products/<company>/`) do not exist yet — all five brands are `published: false` pending owner confirmation. The sitemap and Products hub degrade gracefully.
- Customer logos render as text wordmarks until the owner supplies files and written permission; logo images would add image-search equity but are not required for ranking.
- No `hreflang` — the site is English (en-IN) only; add it only if a second language is ever built.
